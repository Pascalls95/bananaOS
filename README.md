# bananaOS
A web based operating system. Why bananaOS? Idk it sounded cool. This is a project for Hack Club Stardance.

I created this website for fun, as a way to improve my current HTML and CSS as skills, but more so to learn about JavaScript and how it can be used within a webpage. Also, who wouldn't want an operating system about bananas?
This webos currently has 3 main features, a welcome window, and two apps (notepad and settings). I plan to add more apps and features later.
